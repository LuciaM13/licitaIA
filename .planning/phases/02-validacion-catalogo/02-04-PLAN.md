<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| valor_excel_bc3 -> INTEGER centimos | Conversion manual; error de formula inflaria precios 5% |
| INSERT OR IGNORE -> precios.db | Migracion ejecutada dos veces no debe duplicar filas |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | Tampering | precio mal calculado en migracion | mitigate | Formula int(round(val/1.05*100)) obligatoria y documentada en docstring; test_bd_invariante_ci.py falla si el precio BD * 1.05 difiere > 5% del valor Excel |
| T-02-08 | Tampering | SQL injection en VALUES | mitigate | Todos los valores van como parametros con placeholder ?, nunca interpolados en el string SQL |
| T-02-09 | Tampering | Modificacion de filas existentes | accept | INSERT OR IGNORE no modifica; no hay UPDATE en ninguna migracion Phase 2; las filas existentes estan protegidas por convencion LD-10 |
</threat_model>
