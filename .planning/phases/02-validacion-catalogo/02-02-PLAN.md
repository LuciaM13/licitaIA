**PASO 1 — Clasificar cada obra** aplicando el protocolo LD-3:
- Llamar `cargar_bc3(path)` para obtener la lista de partidas

**PASO 2 — Para cada obra in-scope o parcial-in-scope: curar su MappingObra**

Para cada campo del MappingObra curado usar la estrategia hibrida (LD-5, OQ-2):
- Preferir `PartidaSelector(descripcion_substr="...", capitulo="NN", agregar=True/False)` sobre codigos exactos
- Los capitulos de primer nivel SI son estables entre obras (codigo "01" = OBRA CIVIL ABA, etc.)
- Los codigos de hoja NO son portables — no usar como selector primario

Campos a curar por obra:

a. `es_aba` / `es_san`: True si la obra tiene capitulos ABA / SAN respectivamente

b. `longitud_zanja_aba_m`: PartidaSelector buscando partidas de excavacion ABA
   - substr tipico: "excavacion" o "excav" en capitulo "01" (OBRA CIVIL ABA)
   - agregar=True para sumar todas las filas de excavacion del capitulo
   - El valor de `medicion` de las partidas de excavacion es metros lineales de zanja
   - Si hay varias subcapas (mecanica + manual) usar agregar=True para sumarlas

c. `profundidad_aba_m`: float fijo derivado de la descripcion de la partida de excavacion
   - Buscar patrones como "< 2,50 m", "< 3,50 m" o "h < X" en las descripciones
   - Si la obra especifica un rango, usar el valor del limite superior como profundidad dominante
   - Si es ambiguo, usar 1.20 (ABA poco profunda) y documentar en notas
   - NUNCA inventar — si no se puede derivar, documentar como "no derivable del BC3" en notas

d. `n_acometidas_aba`: PartidaSelector buscando partidas de acometidas ABA
   - substr tipico: "localizacion acometida" o "punto de conexion" en capitulo ABA
   - agregar=True, sumar medicion (cada unidad es 1 acometida)

e. `m2_acerado_aba`: PartidaSelector buscando demolicion de acerado ABA
   - substr tipico: "demolicion" + "acerado" o "soleria" en capitulo ABA o pavimentacion ABA
   - agregar=True para sumar m2

f. `m2_calzada_aba`: PartidaSelector para demolicion calzada ABA (similar a acerado)

g. `pct_seguridad`: derivar del capitulo Seguridad y Salud del BC3
   - Calcular: importe_SyS / PEM_BC3_total
   - Si el BC3 muestra ~2% usar 0.02; si ~3% usar 0.03; si ~4-5% (obras FC) usar el valor exacto
   - Documentar el calculo en notas del MappingObra

h. `tiene_fibrocemento`: True si se detecta "fibrocemento", "fibrocemento", "fc" o "amianto" en descripciones

i. `notas`: string con el razonamiento de cada decision de mapping no obvia

```python
# Clasificacion cualitativa de las 7 obras
# Aplicar protocolo LD-3 a cada obra

clasificaciones = []
for mapping in MAPPINGS:
    xlsx_path = OBRAS_DIR / f"{mapping.expediente}*.xlsx"
    # Intentar cargar; si no existe, marcar como "fichero no disponible"
    import glob
    candidatos = glob.glob(str(OBRAS_DIR / "*.xlsx"))
    # Buscar por expediente en el nombre del fichero
    matches = [c for c in candidatos if mapping.expediente in c]
    
    if not matches:
        clasificaciones.append({
            "expediente": mapping.expediente,
            "nombre": mapping.nombre_obra,
            "clasificacion": "no disponible",
            "motivo": "Fichero xlsx no encontrado en data/proyectos_individuales/",
        })
        continue
    
    bc3 = cargar_bc3(Path(matches[0]))
    por_capitulo = agrupar_por_capitulo(bc3)
    pem_total = sum(por_capitulo.values())
    
    clasificaciones.append({
        "expediente": mapping.expediente,
        "nombre": mapping.nombre_obra,
        "pem_bc3": round(pem_total, 2),
        "capitulos": list(por_capitulo.keys()),
        "fibrocemento": mapping.tiene_fibrocemento,
        "clasificacion": "out-of-scope" if "OUT-OF-SCOPE" in mapping.notas else (
            "parcial-in-scope" if "parcial" in mapping.notas.lower() else "in-scope"
        ),
        "motivo": mapping.notas,
    })

# Imprimir tabla
print(f"{'Expediente':<15} {'Nombre':<20} {'PEM BC3':>12} {'Clasif.':<20} {'FC'}")
print("-" * 80)
for c in clasificaciones:
    pem_str = f"{c.get('pem_bc3', 0):>12,.2f}" if c.get('pem_bc3') else f"{'—':>12}"
    fc_str = "si" if c.get('fibrocemento') else "no"
    print(f"{c['expediente']:<15} {c['nombre']:<20} {pem_str} {c['clasificacion']:<20} {fc_str}")
```
